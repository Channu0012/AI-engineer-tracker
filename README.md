## ⚡ Key Features

- **Password Protected:** Secure student access lock before entering the classroom (`Channu@12345`).
- **Sequential Lesson Locking:**
  - Multi-part weeks (Part 1 & Part 2) enforce strict sequential progress.
  - Part 2 unlocks only after Part 1 is completed.
  - Future weeks unlock only when all previous lessons are finished.
- **Auto-Play & Auto-Advance:**
  - Embedded YouTube player automatically starts when opening a lesson.
  - Automatically advances to the next lesson/week upon completion.
  - Automatically stops/pauses when returning to the Home page.
- **Dynamic Resume Engine:**
  - Home page remembers your progress and defaults to your exact next unfinished lesson.
- **Production Capstones & Job Readiness:**
  - Capstone Projects tracker (Full-Stack AI App + Agentic AI System).
  - 21-point interview and technical readiness checklist.
- **Fully Responsive & Clean Design:**
  - Zero horizontal overflow (`overflow-x: hidden`).
  - Mobile slide-out curriculum drawer.
  - Light mode Coursera aesthetic.


2. **Run locally:**
   - Double-click `index.html` to run directly in any browser, or
